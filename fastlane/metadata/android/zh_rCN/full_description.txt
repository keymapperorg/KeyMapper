给你的键盘或者手柄制作自定义宏，在任意应用中制作屏幕按钮，从你的音量按钮解锁新功能！

Key Mapper 支持各种各样的按钮和按键*：

- 你的手机上所有按钮（音量和侧键）
- 游戏控制器（方向键，ABXY 和多数其他）
- 键盘
- 耳机和头戴式耳机
- 指纹传感器

按键不够？设计你自己的屏幕按钮布局并像真正的按键那样重新映射它们！


我可以制作什么快捷方式？
--------------------------

超过一百个单独的操作，天空才是极限。
用屏幕点击和手势、键盘输入、打开应用、控制媒体构建复杂的宏，甚至直接发送 intents 到其他应用。


我能控制多少？
---------------------------

触发器：你决定怎样触发一个按键映射。长按，双击，按多少次如你所愿！在不同设备上组合按键，甚至包括你的屏幕按钮。

操作：为你想做的事设计特定的宏。组合超过一百个操作，并选择每个之间的延迟。设置重复操作来自动和加速缓慢的任务。

约束：你选择按键映射应该什么时候运行，和什么时候不应该运行。仅在一个特定的应用中需要它？或者当媒体正在播放时？在你的锁屏上？为最大的控制约束你的按键映射。

* 已支持多数设备，未来会添加新设备。如果它不对你起作用，告诉我们，我们可以优先处理你的设备。

当前不支持：
 - 鼠标按钮
 - 操纵杆和手柄上的按键(LT,RT)


安全和无障碍服务
---------------------------

这个应用包含我们的 Key Mapper 无障碍服务，使用安卓无障碍 API 来检测聚焦的应用，并转发按下按键到用户定义的按键映射。它也可以用来在其他应用上绘制辅助的漂浮按钮覆盖层。

接受运行无障碍服务，在你使用你的设备时，本应用会监视键击。它也会模拟滑动和缩放，如果你在本应用中使用这些操作。

它不会收集任何用户数据，或者连接到互联网来发送任何数据到任何地方。

我们的无障碍服务仅由用户触发，在他们的设备上按下物理按键时。在系统无障碍设置中，用户可以随时关闭它。
